FAlCon_core  are the core packages for all applications in the FAlCon 
ecosystem. This includes the ability to cross communicate and 
transfer necessary objects around between instances. FAlCon is a 
Python-based tune-up framework developed for quantum dot devices
While it has been developed to serve the needs of quantum dot device
experiments, it is not inherently limited to such experiments, and can
be used anywhere a system where recursive measurements may be necessary.
